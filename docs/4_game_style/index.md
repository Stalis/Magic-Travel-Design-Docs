# 4. Стиль игры

**Определение:** Особенности геймплея, отличающие игру от других в жанре. Ключевые механики, которые формируют уникальный игровой опыт.

## Ключевые особенности геймплея

### Прецизионное таргетирование
Полный контроль курсора мыши для изучения деталей окружения, точного выбора целей в бою и интерактивности с мелкими объектами.

### Дипломатические возможности  
Диалоговая система с враждебными и нейтральными NPC, позволяющая решать конфликты без боя.

### Походовая боевая система
Тактические бои с полным контролем времени и планирования действий.

### Исследование мира
Детальное изучение игрового пространства с возможностью взаимодействия с любыми объектами.

## Геймплейные принципы

### Гибкость подходов
Игрок может решать задачи различными способами: силой, дипломатией, скрытностью или изобретательностью.

### Внимание к деталям
Каждый объект в мире может нести информацию или быть полезным для решения задач.

### Тактическая глубина
Боевая система предоставляет множество вариантов для планирования и выполнения действий.
