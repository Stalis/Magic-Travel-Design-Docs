# 5.5 Система GridMap

**Определение:** Система пространственной организации игрового мира через дискретную сетку клеток с геймплейными свойствами, независимыми от визуального представления.

### Структура системы

### Иерархия компонентов Unity

**Компоненты карты:**
1. **Map** - корневой компонент уровня, управляет инициализацией
2. **Location** - компонент крупной области карты 
3. **Room** - компонент логического контейнера внутри локации
4. **Cell** - компонент минимальной единицы пространства с координатами
5. **Wall** - компонент барьера между клетками по четырем направлениям

### Система Data-компаньонов

**ScriptableObject структуры:**
- **MapData** - данные карты без привязки к компонентам
- **LocationData** - данные локации
- **RoomData** - данные комнаты  
- **CellData** - данные клетки
- **WallData** - данные стены

**Создание Data объектов:**
- **Вручную разработчиком** - для настраиваемых сущностей
- **Автоматически в Awake** - для стандартных сущностей на основе настроек компонента

### Инициализация системы

### Процесс загрузки карты

**Алгоритм инициализации:**
1. **Триггер загрузки** - в данный момент Start компонента Map, в будущем система загрузки уровня
2. **Сканирование структуры** - Map проходится по всей иерархии дочерних объектов
3. **Сбор данных** - извлечение Data объектов и настроек компонентов
4. **Создание MapRegistry** - построение словаря с координатами как ключами
5. **Валидация** - проверка целостности и корректности данных

**После инициализации:**
- Компоненты используются только для отладки и визуализации в редакторе
- Вся игровая логика работает через MapRegistry

### MapRegistry структура

### Основной словарь

**Техническая реализация:**
```
MapRegistry: ScriptableObject {
    cells: Dictionary<Vector2Int, CellRegistry>
}
```

**Ключи координат:**
- **Vector2Int** - стандартный Unity тип для целочисленных 2D координат
- Прямой доступ O(1) к любой клетке по координатам

### CellRegistry структура

**Содержимое записи:**
```
CellRegistry {
    // Параметры клетки (ScriptableVariable ссылки)
    isWalkable: ScriptableVariable<bool>
    isTransparent: ScriptableVariable<bool>
    isPiercable: ScriptableVariable<bool>
    
    // Параметры 4х прилегающих стен (по сторонам света)
    northWall: WallProperties (ScriptableVariable ссылки)
    eastWall: WallProperties (ScriptableVariable ссылки)
    southWall: WallProperties (ScriptableVariable ссылки)
    westWall: WallProperties (ScriptableVariable ссылки)
}
```

**Динамические изменения:**
- Свойства хранятся как ссылки на ScriptableVariable
- Изменение переменной автоматически влияет на игровую логику
- Позволяет реализовать двери, ловушки, временные препятствия
- Примеры: дверь меняет walkable/transparent/piercable по событию

### Система координат

**Направления стен:**
- **North** - верхняя граница клетки
- **East** - правая граница клетки  
- **South** - нижняя граница клетки
- **West** - левая граница клетки

### Свойства элементов

### Свойства клеток

**isWalkable** - проходимость для движения:
- `true`: актор может занимать эту клетку
- `false`: клетка заблокирована для движения

**isTransparent** - прозрачность для обзора:
- `true`: через клетку проходит линия видимости
- `false`: клетка блокирует обзор

**isPiercable** - проницаемость для снарядов:
- `true`: через клетку могут проходить дистанционные атаки
- `false`: клетка блокирует снаряды

### Свойства стен

**Стены используют те же свойства** с аналогичной логикой:
- **isWalkable**: можно ли пройти через стену (двери)
- **isTransparent**: блокирует ли стена обзор
- **isPiercable**: можно ли стрелять через стену

**Примеры конфигураций:**
- Открытый проход: `walkable=true, transparent=true, piercable=true`
- Дверь: `walkable=true, transparent=false, piercable=false`
- Решетка: `walkable=false, transparent=true, piercable=false`

### API MapRegistry

### Методы реестра

**Получение свойств:**
- `MapRegistry.GetCellProperty(Vector2Int coordinates, property)` - свойство клетки
- `MapRegistry.GetWallProperty(Vector2Int coordinates, Direction direction, property)` - свойство стены
- `MapRegistry.IsWalkable(Vector2Int coordinates)` - быстрая проверка проходимости
- `MapRegistry.IsTransparent(Vector2Int coordinates)` - быстрая проверка прозрачности

**Пространственные операции:**
- `MapRegistry.GetAdjacentCells(Vector2Int coordinates)` - соседние клетки
- `MapRegistry.HasCell(Vector2Int coordinates)` - существует ли клетка с такими координатами

### Ограничения и особенности

**Архитектурные решения:**
- Разделение компонентов Unity и игровых данных
- Инициализация структуры карты при загрузке уровня
- Динамические изменения свойств через ScriptableVariable

**Текущие ограничения:**
- Структура карты (координаты клеток/стен) статична после инициализации
- Нельзя добавлять/удалять клетки или стены во время игры
- Можно изменять только свойства существующих элементов
