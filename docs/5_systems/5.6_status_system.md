# 5.6 Система состояний

**Определение:** Система управления временными и постоянными эффектами, применяемыми к акторам. Состояния влияют на характеристики, поведение и взаимодействие с игровыми системами.

### Структура состояния

**Компоненты состояния:**
- **ID** - уникальный строковый идентификатор (например, "poisoned", "blessed", "stunned")
- **Условие завершения** - определяет момент снятия состояния
- **Набор эффектов** - конкретные изменения, применяемые к носителю
- **Метаданные** - название, описание, иконка, тип (бафф/дебафф)

### Условия завершения

### Временные условия

**Счетчик ходов:**
- Состояние завершается через определенное количество ходов носителя
- Счетчик уменьшается в конце каждого хода

**Счетчик раундов:**
- Завершение через определенное количество полных циклов ходов всех участников

### Событийные условия

**Игровые события:**
- Завершение при наступлении определенного события
- Примеры событий: "combat_end", "rest_completed", "day_change"

**Пороговые условия:**
- Снятие при достижении определенных значений ресурсов
- Примеры: здоровье ниже 25%, мана выше 80%

### Постоянные состояния

**Без ограничений по времени:**
- Действуют до явного снятия через действия или другие эффекты

### Комбинированные условия

**Логические операторы:**
- AND: все условия должны быть выполнены для завершения
- OR: любое из условий приводит к завершению
- Вложенные комбинации для сложных сценариев

### Эффекты состояний

### Модификация тегов

**Добавление тегов:**
- Временное присвоение тегов на время действия состояния
- Автоматическое удаление при снятии состояния

**Примеры:**
```
Состояние "Отравление":
- Добавляет тег poisoned
- Завершается через 3 хода

Состояние "Благословение":
- Добавляет тег blessed
- Завершается событием "combat_end"
```

### Модификация ресурсов

**Изменение максимальных значений:**
- Временное увеличение или уменьшение лимитов ресурсов
- Применение множителей к восстановлению/расходованию

**Периодические эффекты:**
- Урон или исцеление в определенные моменты
- Восстановление или истощение ресурсов

**Примеры:**
```
Состояние "Усталость":
- Уменьшает максимум очков действий на 1
- Завершается событием "rest_completed"

Состояние "Регенерация":
- Восстанавливает 3 здоровья в начале каждого хода
- Завершается через 5 ходов
```

### Модификация действий

**Изменение стоимости:**
- Увеличение или уменьшение расхода ресурсов для действий
- Бонусы или штрафы к эффективности

**Ограничения:**
- Блокировка определенных типов действий
- Принуждение к конкретным действиям

**Примеры:**
```
Состояние "Магическое истощение":
- Удваивает стоимость маны для заклинаний
- Завершается через 2 раунда

Состояние "Оглушение":
- Блокирует все действия кроме "пропустить ход"
- Завершается в конце следующего хода
```

### Хуки событий

### Жизненный цикл состояния

**При применении:**
- Активация всех эффектов состояния
- Применение модификаций к носителю

**При снятии:**
- Деактивация всех эффектов
- Восстановление исходных значений

### Игровые события

**Начало хода носителя:**
- Применение периодических эффектов
- Уменьшение счетчиков времени

**Конец хода носителя:**
- Проверка условий завершения
- Применение эффектов конца хода

**Выполнение действий:**
- Модификация действий в реальном времени
- Дополнительные эффекты при определенных типах действий

**Получение урона:**
- Модификация входящего урона
- Активация реактивных эффектов

### Стекирование состояний

### Политики стекирования

**Уникальные состояния:**
- Только одно состояние данного типа на актора
- При повторном применении - обновление длительности или замена

**Стекируемые состояния:**
- Несколько экземпляров одного типа действуют независимо
- Каждый стек имеет собственную длительность

**Ограниченное стекирование:**
- Максимальное количество стеков (например, до 5)
- Эффект может усиливаться с количеством стеков

**Примеры:**
```
Отравление (Уникальное):
- Второе применение обновляет длительность до максимума

Кровотечение (Стекируемое):
- Каждый стек наносит урон независимо
- Максимум 3 стека

Ярость (Ограниченное стекирование):
- До 5 стеков, каждый +10% к урону
- При превышении лимита обновляется длительность
```

### Взаимодействие состояний

**Подавление:**
- Одни состояния блокируют действие других
- Иерархия приоритетов для разрешения конфликтов

**Взаимное исключение:**
- Автоматическое снятие конфликтующих состояний
- Иммунитет к определенным типам эффектов

**Примеры:**
```
Заморозка подавляет Горение:
- При применении заморозки горение временно неактивно
- При снятии заморозки горение продолжает действовать

Благословение исключает Проклятие:
- Применение одного автоматически снимает другое
```

### Категории состояний

### По типу воздействия

**Баффы:**
- Положительные эффекты, улучшающие характеристики
- Примеры: благословение, ускорение, защита

**Дебаффы:**
- Отрицательные эффекты, ухудшающие состояние
- Примеры: отравление, проклятие, замедление

**Нейтральные:**
- Изменяют поведение без явной пользы или вреда
- Примеры: маскировка, трансформация

### По длительности

**Мгновенные:**
- Применяют эффект и сразу завершаются
- Используются для одноразовых модификаций

**Временные:**
- Действуют определенное количество ходов/раундов
- Большинство боевых эффектов

**Длительные:**
- Снимаются определенными событиями
- Примеры: усталость до отдыха, проклятие до снятия

**Постоянные:**
- Действуют без ограничений по времени
- Используются для permanent модификаций

### Технические принципы

**Производительность:**
- Обновление состояний происходит только при необходимости
- Кэширование модификаторов для частых проверок

**Валидация:**
- Проверка корректности стекирования при применении
- Автоматическое разрешение конфликтов между состояниями

**Расширяемость:**
- Новые типы эффектов добавляются без изменения core системы
- Конфигурация состояний через внешние файлы данных
