# 5.7 Система характеристик

**Определение:** Система управления числовыми параметрами акторов (сила, ловкость, интеллект и др.) с поддержкой модификаторов от различных источников.

### Базовые концепции

### Характеристика (Stat)

**Определение:** Числовой параметр актора, который может изменяться через модификаторы от различных источников.

**Примеры характеристик:**
- Сила, ловкость, выносливость - физические атрибуты
- Интеллект, мудрость, харизма - ментальные атрибуты
- Меткость, скрытность, удача - специальные атрибуты

**Компоненты характеристики у актора:**
- **Тип характеристики** - ссылка на StatDefinition
- **Базовое значение** - исходное значение без модификаторов
- **Модификаторы** - список активных изменений от различных источников
- **Итоговое значение** - рассчитанное значение с учетом всех модификаторов

### StatDefinition структура

**ScriptableObject описание:**
```
StatDefinition : ScriptableObject {
    id: string              // Уникальный идентификатор характеристики
    displayName: string     // Название для UI
    description: string     // Описание назначения характеристики
    defaultValue: int       // Значение по умолчанию
    minValue: int           // Минимально возможное значение
    maxValue: int           // Максимально возможное значение (если ограничено)
    hasMaxLimit: bool       // Есть ли верхний предел
}
```

### StatModifier структура

**Модификатор характеристики:**
```
StatModifier {
    value: int              // Значение модификатора
    type: ModifierType      // Тип модификатора (Flat/Percent)
    source: string          // Источник модификатора
    isPermanent: bool       // Постоянный или временный модификатор
}
```

### ModifierType enum

**Типы модификаторов:**
- `Flat` - плоский модификатор (прибавляется к базовому значению)
- `Percent` - процентный модификатор (умножает итоговое значение)

### Техническая реализация

### Компоненты системы

**StatManager** - основной компонент системы:
- Управление регистрацией типов характеристик
- Предоставление глобального API для работы с характеристиками
- Валидация типов характеристик

**ActorStatContainer** - компонент актора:
- Хранение характеристик конкретного актора
- Применение и управление модификаторами
- Расчет итоговых значений характеристик

**StatRegistry** - реестр типов характеристик:
- Словарь зарегистрированных StatDefinition
- Валидация определений характеристик

### Структуры данных

### ActorStatContainer структура

**Хранение характеристик актора:**
```
ActorStatContainer : MonoBehaviour {
    stats: Dictionary<string, StatInstance>     // Характеристики по типу (StatDefinition.id)
    isInitialized: bool                         // Завершена ли инициализация
}
```

### StatInstance структура

**Экземпляр характеристики у актора:**
```
StatInstance {
    statType: StatDefinition            // Ссылка на тип характеристики
    baseValue: int                      // Базовое значение
    modifiers: List<StatModifier>       // Активные модификаторы
    cachedFinalValue: int               // Кэшированное итоговое значение
    isDirty: bool                       // Нужен ли пересчет
}
```

### Алгоритмы работы с характеристиками

### Расчет итогового значения

**Алгоритм расчета характеристики:**
1. **Проверка кэша** - если isDirty = false, вернуть cachedFinalValue
2. **Сбор плоских модификаторов** - сумма всех Flat модификаторов
3. **Расчет промежуточного значения** - baseValue + сумма плоских модификаторов
4. **Сбор процентных модификаторов** - произведение всех Percent модификаторов
5. **Расчет итогового значения** - промежуточное значение * произведение процентных модификаторов
6. **Применение ограничений** - проверка minValue и maxValue если hasMaxLimit = true
7. **Кэширование результата** - сохранение в cachedFinalValue, isDirty = false

### Добавление модификатора

**Алгоритм добавления модификатора:**
1. **Валидация источника** - проверка что модификатор от того же источника не существует
2. **Добавление в список** - добавление в modifiers
3. **Инвалидация кэша** - isDirty = true
4. **Генерация события** - OnStatModifierAdded

### Удаление модификатора

**Алгоритм удаления модификатора:**
1. **Поиск модификатора** - по источнику или конкретному экземпляру
2. **Удаление из списка** - удаление из modifiers
3. **Инвалидация кэша** - isDirty = true
4. **Генерация события** - OnStatModifierRemoved

### API системы

### Основные методы StatManager

**Управление типами характеристик:**
- `StatManager.RegisterStatType(StatDefinition statDef)` → bool
- `StatManager.GetStatType(string statId)` → StatDefinition
- `StatManager.IsStatTypeRegistered(string statId)` → bool

### Основные методы ActorStatContainer

**Управление характеристиками:**
- `ActorStatContainer.SetBaseStat(string statId, int value)` → bool
- `ActorStatContainer.GetStatValue(string statId)` → int
- `ActorStatContainer.GetBaseStatValue(string statId)` → int

**Управление модификаторами:**
- `ActorStatContainer.AddModifier(string statId, StatModifier modifier)` → bool
- `ActorStatContainer.RemoveModifier(string statId, string source)` → bool
- `ActorStatContainer.RemoveAllModifiersBySource(string source)` → int
- `ActorStatContainer.GetModifiers(string statId)` → List<StatModifier>

**Проверка характеристик:**
- `ActorStatContainer.HasStat(string statId)` → bool
- `ActorStatContainer.GetAllStats()` → Dictionary<string, int>

### Инициализация системы

### Загрузка типов характеристик

**Процесс инициализации StatManager:**
1. **Загрузка StatRegistry** - получение списка StatDefinition от разработчика
2. **Валидация определений** - проверка уникальности ID и корректности параметров
3. **Регистрация типов** - создание словаря для быстрого доступа O(1)

### Инициализация ActorStatContainer

**Процесс инициализации актора:**
1. **Получение начальных характеристик** - список StatDefinition из Inspector или StatProfile
2. **Создание экземпляров** - создание StatInstance для каждой характеристики
3. **Установка базовых значений** - baseValue = defaultValue из StatDefinition
4. **Валидация характеристик** - проверка что все типы зарегистрированы в StatManager
5. **Установка isInitialized = true** - система готова к работе

### События системы

**События изменения характеристик:**
- **OnStatValueChanged** - итоговое значение характеристики изменилось
- **OnStatModifierAdded** - модификатор добавлен к характеристике
- **OnStatModifierRemoved** - модификатор удален у характеристики
- **OnBaseStatChanged** - базовое значение характеристики изменилось

**Структура события:**
```
StatEvent {
    actor: Actor
    statId: string
    oldValue: int
    newValue: int
    changeType: StatChangeType   // ValueChanged, BaseChanged, ModifierAdded, ModifierRemoved
    source: string              // Источник изменения (для модификаторов)
    timestamp: float
}
```

### Примеры использования

### Конфигурация характеристик

**Сила (физический атрибут):**
```
StrengthStat: {
    id: "strength"
    defaultValue: 10
    minValue: 1
    maxValue: 20
    hasMaxLimit: true
}
```

**Интеллект (ментальный атрибут):**
```
IntelligenceStat: {
    id: "intelligence"
    defaultValue: 10
    minValue: 1
    maxValue: 0
    hasMaxLimit: false
}
```

**Меткость (специальный атрибут):**
```
AccuracyStat: {
    id: "accuracy"
    defaultValue: 50
    minValue: 0
    maxValue: 100
    hasMaxLimit: true
}
```

### Примеры работы с модификаторами

**Бонус от экипировки:**
```csharp
var strengthBonus = new StatModifier {
    value = 5,
    type = ModifierType.Flat,
    source = "magic_sword",
    isPermanent = false
};
container.AddModifier("strength", strengthBonus);
```

**Процентный бонус от состояния:**
```csharp
var blessBonus = new StatModifier {
    value = 20,  // +20%
    type = ModifierType.Percent,
    source = "blessed_status",
    isPermanent = false
};
container.AddModifier("strength", blessBonus);
```

### Пример расчета итогового значения

**Характеристика "Сила":**
- Базовое значение: 10
- Модификатор от меча: +5 (Flat)
- Модификатор от зелья: +2 (Flat)
- Модификатор от благословения: +20% (Percent)

**Расчет:**
```
Плоские модификаторы: +5 +2 = +7
Промежуточное значение: 10 + 7 = 17
Процентные модификаторы: +20% = 1.2
Итоговое значение: 17 * 1.2 = 20.4 (округляется до 20)
```

### Ограничения и особенности

**Архитектурные решения:**
- StatDefinition как ScriptableObjects для удобства настройки в редакторе
- Разделение определений типов (StatManager) и экземпляров у акторов (ActorStatContainer)
- Ленивый расчет итоговых значений с кэшированием для производительности
- Система событий для интеграции с другими системами без прямой связанности

**Текущие ограничения:**
- Только целочисленные значения характеристик
- Статический набор типов характеристик (регистрируются при инициализации)
- Простая формула расчета (плоские затем процентные модификаторы)
- Один модификатор от одного источника на характеристику
