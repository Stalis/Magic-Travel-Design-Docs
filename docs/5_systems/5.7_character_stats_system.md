# 5.7 Система характеристик

**Определение:** Система численных параметров акторов и их модификации. Управляет характеристиками и их изменением через различные игровые эффекты.

### Универсальность системы

**Принцип единообразия:**
- Все персонажи используют одинаковую систему характеристик
- Никаких исключений на уровне системы
- Различия реализуются через механики (классы, расы, прогрессия)

**Охват системы:**
- Аватар игрока
- Спутники партии
- Враждебные персонажи
- Активные NPC

### Типы характеристик

### Базовые характеристики

**Определение:** Первичные численные параметры, которые определяются при создании актора и могут изменяться через игровые механики.

**Свойства:**
- Имеют базовое значение
- Могут быть модифицированы временно и постоянно
- Служат основой для расчета других параметров

### Производные характеристики

**Определение:** Параметры, рассчитываемые на основе базовых характеристик и других факторов.

**Свойства:**
- Рассчитываются автоматически при изменении базовых характеристик
- Могут иметь собственные модификаторы
- Часто связаны с ресурсами системы ресурсов

### Связь с системой ресурсов

**Влияние на Consumables:**
- Характеристики могут определять максимальные значения ресурсов
- Влияют на скорость восстановления ресурсов
- Модифицируют эффективность расходования ресурсов

**Примеры связей:**
```
Характеристика → Ресурс:
- Физическая сила → Максимальное здоровье
- Умственная сила → Максимальная энергия  
- Скорость → Очки действий за ход
```

### Модификация характеристик

### Источники модификаторов

**Состояния:**
- Временные баффы и дебаффы
- Длительные эффекты
- Модификации от окружающей среды

**Экипировка:**
- Постоянные бонусы от надетых предметов
- Зачарования и улучшения
- Штрафы от поврежденной экипировки

**Способности:**
- Пассивные эффекты от навыков
- Особенности персонажа
- Модификаторы от механик

### Типы модификаторов

**Плоские модификаторы:**
- Добавляются к базовому значению
- Пример: +5 к характеристике от предмета

**Процентные модификаторы:**
- Применяются к итоговому значению
- Пример: +20% к характеристике от способности

**Порядок применения:**
1. Базовое значение характеристики
2. Плоские модификаторы (суммируются)
3. Процентные модификаторы (перемножаются)

### Расчет итоговых значений

### Формула общего расчета

```
Итоговое_Значение = (Базовое_Значение + Сумма_Плоских_Модификаторов) * Произведение_Процентных_Модификаторов
```

### Пример расчета

**Характеристика персонажа:**
- Базовое значение: 10
- Бонус от экипировки: +3
- Бонус от состояния: +2
- Штраф от эффекта: -1
- Процентный бонус: +20%

**Расчет:**
```
Плоские модификаторы: +3 +2 -1 = +4
Базовое значение с модификаторами: 10 + 4 = 14
Процентный модификатор: +20% = 1.2
Итоговое значение: 14 * 1.2 = 16.8 (округляется до 17)
```

### Интеграция с игровыми системами

### Система действий

**Влияние на действия:**
- Модификация стоимости действий
- Изменение эффективности действий
- Доступность определенных действий

### Система состояний

**Взаимодействие с эффектами:**
- Состояния могут модифицировать характеристики
- Характеристики влияют на сопротивляемость состояниям
- Пороговые проверки для применения эффектов

### Система тегов

**Динамическая классификация:**
- Характеристики могут влиять на применимость тегов
- Пороговые значения для автоматического присвоения тегов
- Условная совместимость действий на основе характеристик

### Технические принципы

**Производительность:**
- Кэширование рассчитанных значений
- Пересчет только при изменении модификаторов
- Пакетное обновление связанных характеристик

**Валидация:**
- Автоматическая проверка корректности значений
- Предупреждения о некорректных модификаторах
- Защита от критических ошибок в расчетах

**Расширяемость:**
- Легкое добавление новых типов характеристик
- Поддержка пользовательских модификаторов
- Конфигурируемые формулы расчета
