# 5.6 Система инвентаря

**Определение:** Система базовых компонентов для создания любых типов инвентарей и систем предметов. Предоставляет "строительные блоки" для механик, а не готовые решения.

### Предоставляет другим системам
- Базовые компоненты для создания предметов
- Универсальную систему контейнеров с настраиваемыми ограничениями
- Гибкую классификацию предметов через теги
- Интерфейсы для кастомной сортировки и фильтрации
- Основу для реализации торговли, экипировки, расходников

---

## Базовые компоненты

### ItemData (ScriptableObject)

**Определение:** Базовый класс для описания любого предмета в игре.

**Структура:**
```
ItemData : ScriptableObject {
    id: string                  // Уникальный идентификатор
    displayName: string         // Название для UI
    description: string         // Описание предмета
    icon: Sprite               // Иконка предмета
    
    itemTags: List<string>     // Теги предмета (weapon, armor, consumable, etc.)
    
    isStackable: bool          // Можно ли складывать в стеки
    maxStackSize: int          // Максимальный размер стека
    
    weight: float              // Вес предмета
    value: int                 // Базовая стоимость
    rarity: ItemRarity         // Редкость (enum)
}
```

**Принципы:**
- Максимально общий - подходит для любых типов предметов
- Расширяемый - дочерние классы добавляют специфичную функциональность
- Не содержит игровой логики - только данные

### SlotDefinition (ScriptableObject)

**Определение:** Описание слота контейнера с ограничениями и правилами размещения предметов.

**Структура:**
```
SlotDefinition : ScriptableObject {
    id: string                     // Уникальный ID типа слота
    displayName: string            // Название для UI
    
    requiredTags: List<string>     // Предмет ДОЛЖЕН иметь все эти теги
    allowedTags: List<string>      // Предмет может иметь любой из этих тегов
    forbiddenTags: List<string>    // Предмет НЕ должен иметь эти теги
    
    maxWeight: float               // Максимальный вес предмета в слоте
    allowStacking: bool            // Разрешено ли стекирование в этом слоте
    
    slotIcon: Sprite              // Иконка пустого слота
}
```

**Примеры конфигурации:**
- Слот шлема: `requiredTags: ["equipment", "armor", "head"]`
- Слот расходников: `allowedTags: ["consumable", "potion", "scroll"]`
- Универсальный слот: без ограничений

### ItemContainer (MonoBehaviour)

**Определение:** Универсальный контейнер для предметов с настраиваемыми слотами и правилами.

**Структура:**
```
ItemContainer : MonoBehaviour {
    slots: List<ContainerSlot>     // Конфигурация слотов
    
    maxTotalWeight: float          // Общий лимит веса
    maxTotalItems: int             // Общий лимит количества предметов
    
    // События для интеграции с UI
    OnItemAdded, OnItemRemoved, OnContainerChanged
}

ContainerSlot {
    slotDefinition: SlotDefinition    // Ссылка на определение слота
    currentItem: ItemInstance         // Текущий предмет в слоте
    isLocked: bool                   // Заблокирован ли слот
}

ItemInstance {
    itemData: ItemData               // Ссылка на данные предмета
    quantity: int                    // Количество в стеке
    instanceId: string               // Уникальный ID экземпляра
    customProperties: Dictionary     // Дополнительные свойства (зачарования, прочность)
}
```

### Интерфейс сортировки

**Определение:** Система для создания кастомных алгоритмов сортировки контейнеров.

**Принцип:**
```
IContainerSorter {
    SortItems(items) → sorted_items
    GetSortKey(item) → comparable_key
    SorterName → string
}
```

**Типы сортировщиков:**
- По типу предмета (первый тег)
- По стоимости
- По редкости
- Комбинированная сортировка (цепочка критериев)

## API системы

### Основные операции контейнера

**Управление предметами:**
- Добавление предметов с проверкой совместимости слотов
- Удаление предметов по ID и количеству
- Перемещение предметов между слотами
- Поиск предметов по различным критериям

**Проверки и валидация:**
- Проверка возможности добавления предмета
- Поиск совместимых слотов для предмета
- Получение статистики контейнера (вес, стоимость, количество)

**Организация и сортировка:**
- Применение алгоритмов сортировки
- Автоматическая оптимизация размещения
- Объединение стеков одинаковых предметов

**Фильтрация:**
- Поиск предметов по тегам
- Поиск по типу данных предмета
- Поиск по кастомным условиям
