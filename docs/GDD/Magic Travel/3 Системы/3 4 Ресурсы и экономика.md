# 3.4 Ресурсы и экономика

### Ресурсы (Consumables)

**Определение:** Любые хранимые и расходуемые значения, принадлежащие актору или группе акторов.

**Категории ресурсов:**

### Жизненные ресурсы

- **Здоровье (Health Points)** - основной ресурс выживания
- **Мана/Энергия** - ресурс для использования способностей и физических действий

### Игровые валюты

- Золото, деньги
- Очки опыта
- Репутация
- Специальные валюты (очки вдохновения, кармические очки)

### Предметы и инвентарь

- Расходуемые предметы (зелья, свитки)
- Боеприпасы
- Ключевые предметы
- Материалы для крафта

**Свойства ресурсов:**
- Максимальное значение
- Текущее значение
- Скорость восстановления
- Условия расходования

### Очки действий (Action Points)

**Определение:** Consumable ресурс, определяющий количество действий, которые может выполнить Turn Actor за один ход. Очки действий работают по тем же принципам, что и другие ресурсы (мана, здоровье).

### Архитектурное решение

Очки действий реализованы как обычный consumable ресурс, а не как параметр самого действия. Это обеспечивает:
- Единообразную систему управления всеми ресурсами
- Возможность динамически модифицировать стоимость действий
- Универсальные механики для эффектов и способностей

### Типы очков действий

**Основные очки действий (Primary Action Points):**
- Тратятся на ключевые действия (атака, заклинания, движение)
- **По умолчанию:** максимум 1 очко, восстанавливается каждый раунд до максимального значения
- Способности и состояния могут изменять максимальное значение

**Дополнительные очки действий (Bonus Action Points):**
- Используются для второстепенных действий (использование предметов, простые взаимодействия)
- **По умолчанию:** максимум 1 очко, восстанавливается каждый раунд до максимального значения
- Способности и состояния могут изменять максимальное значение

**Свойства ресурса очков действий:**
- Максимальное значение (может изменяться от способностей и состояний)
- Текущее значение
- Правила восстановления (обычно полное восстановление каждый раунд)
- Возможность модификации через эффекты

### Взаимодействие с системой действий

- Действия имеют базовую стоимость по каждому типу ресурсов
- Финальная стоимость рассчитывается с учетом всех активных эффектов
- Система ресурсов проверяет наличие и списывает необходимые очки

**Примеры модификации через состояния и способности:**
- Увеличение максимума очков действий на один ход или постоянно
- Конвертация дополнительных очков в основные
- Снижение стоимости определенных типов действий
- Возможность “переплачивать” другими ресурсами (здоровьем, маной)
- Способности, позволяющие переносить неиспользованные очки на следующий ход
