# 3.3 Система ходов

### Базовые концепции

### Ход (Turn)

**Определение:** Основная единица времени в игре. За один ход актор может выполнить определенный набор действий или пропустить ход.

**Структура хода:**
1. Начало хода (восстановление ресурсов, применение эффектов)
2. Фаза действий (выполнение действий актора)
3. Завершение хода (применение длительных эффектов, проверка условий)

### Раунд (Round)

**Определение:** Один полный проход по циклу ходов всех активных Turn Actor.

**Этапы раунда:**
1. Определение порядка ходов (по инициативе)
2. Выполнение ходов всех акторов
3. Применение эффектов конца раунда
4. Подготовка к следующему раунду

### Инициатива (Initiative)

**Определение:** Числовая величина, определяющая порядок ходов Turn Actor в рамках раунда.

**Принципы:**
- Чем выше значение, тем раньше ход
- При равных значениях используются дополнительные критерии (скорость, случайность)
- Может изменяться в процессе игры через способности или эффекты

### Режимы ходов

### Строгий режим ходов (Turn-Based Mode)

**Характеристики:**
- Ходы выполняются строго последовательно
- Каждая сущность ждет завершения хода предыдущей
- Полный контроль над временем и планированием

**Применение:**
- Тактические бои
- Головоломки, требующие точного планирования
- Ситуации с высокой сложностью

### Real-time режим ходов

**Характеристики:**
- Игрок может действовать в любое время
- ИИ-сущности действуют по таймеру (например, каждые 2 секунды)
- Возможна рассинхронизация количества ходов

**Преимущества:**
- Более динамичный геймплей
- Подходит для исследования и простых взаимодействий
- Снижает нагрузку на планирование

**Переключение режимов:**
- По команде игрока
- Автоматически при определенных событиях (начало боя)
- Через игровые сценарии
