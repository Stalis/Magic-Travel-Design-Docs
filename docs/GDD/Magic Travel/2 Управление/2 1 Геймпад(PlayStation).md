# 2.1 Геймпад(PlayStation)

## Основное движение и навигация

| Элемент управления | Функция |
| --- | --- |
| Левый стик | Передвижение партии по клеткам / Нацеливание скиллов и атак |
| Правый стик | Поворот камеры/партии на 90° (горизонтальная ось), разворот на 180° (вниз) |
| L1/R1 | Быстрое переключение между персонажами в партии |

## Основные действия

| Кнопка | Функция |
| --- | --- |
| X | Основное действие (атака, взаимодействие, подтверждение) |
| Квадрат | Контекстное меню взаимодействий (поговорить/осмотреть/атаковать) |
| Треугольник | Удержание: управление ходами (завершить ход/пропустить ход) |
| Круг | Отмена/назад/пропуск хода |

## Быстрый доступ

| Элемент управления | Функция |
| --- | --- |
| L2 | Меню быстрых скиллов текущего персонажа (удерживать + любой стик для навигации, X или нажатие стика для выбора) |
| R2 | Меню быстрых предметов (удерживать + любой стик для навигации, X или нажатие стика для выбора) |
| Крестовина | Быстрое переключение между целями: Лево/Право - слева направо, Верх/Низ - ближние/дальние |

## Системные функции

| Кнопка | Функция |
| --- | --- |
| Тачпад | Карта мира |
| Options | Главное меню/пауза |
| Share | Экран характеристик персонажей/инвентарь |

## Контекстные действия

| Комбинация | Функция |
| --- | --- |
| Квадрат на цели | Контекстное меню взаимодействий (поговорить/осмотреть/атаковать) |
| L3 (нажатие левого стика) | Добровольное переключение режимов хода (квази-реалтайм ↔︎ пошаговый) |
| R3 (нажатие правого стика) | Приближение/отдаление камеры (переключение между двумя уровнями) |
