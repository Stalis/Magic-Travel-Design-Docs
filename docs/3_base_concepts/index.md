# 3. Основные понятия

**Определение:** Базовые термины, концепции и принципы, необходимые для понимания игровых систем и механик.

## Глоссарий специфических терминов

**ООД** - Очки Основного Действия (Primary Action Points)

**ДОД** - Дополнительные Очки Действий (Bonus Action Points)

**Turn Actor** - актор, который может выполнять ходы в системе ходов

**Action Target** - актор, который может быть целью действий других акторов

**Consumables** - расходуемые ресурсы (мана, здоровье, очки действий и т.д.)

**Актор** - любой игровой объект, участвующий в игровых системах

**GridMap** - система пространственной организации через дискретную сетку клеток

**Клетка (Cell)** - минимальная единица пространства с геймплейными свойствами

**Стена (Wall)** - барьер между клетками по четырем направлениям

**Состояние (Status)** - временные или постоянные эффекты, применяемые к акторам

**Характеристика (Stat)** - численный параметр актора, определяющий его возможности

**Механика (Mechanic)** - геймплейная активность с жизненным циклом, использующая системы

*Конвенциональные термины (мана, здоровье, NPC, AI, UI и т.д.) используются в общепринятом значении*
