# 3.1 Основные понятия

### Актор (Actor)

**Определение:** Любой игровой объект, который может участвовать в игровых системах - выполнять действия, быть целью действий, или и то, и другое.

**Принцип работы:**
Каждая игровая система определяет своих акторов - объекты, с которыми эта система может работать. Один и тот же объект может быть актором нескольких систем одновременно.

**Примеры:**
- Персонаж игрока может быть Turn Actor (выполняет ходы), Action Target (может быть целью лечения), Dialog Actor (ведет диалоги)
- Дверь может быть только Action Target (можно открыть/сломать)
- Туман может быть только Turn Actor (рассеивается со временем)

**Технические особенности:**
- Каждый актор имеет набор характеристик и тегов для валидации взаимодействий
- Актор может динамически приобретать или терять возможности участия в системах
- Системы используют классификацию характеристик для определения совместимости

### Игровой сценарий (Game Script)

**Определение:** Записанная программным кодом последовательность действий, которая может быть запущена действиями игрока или другими акторами в зависимости от условий.

**Структура сценария:**
- **Условия активации** (триггеры)
- **Предварительные условия** (preconditions)
- **Последовательность действий**
- **Условия завершения**

**Типы сценариев:**
- Квестовые сценарии
- Боевые события
- Изменения окружения
- Диалоговые системы
- Системы прогрессии
