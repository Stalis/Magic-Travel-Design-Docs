# 7. Параметры

**Определение:** Централизованное хранилище настроек балансировки для всех игровых систем. Содержит численные параметры, которые влияют на геймплей и могут быть изменены для тестирования и балансировки.

**Принципы:**
- Все системы ссылаются на параметры из этого раздела
- Изменение параметра автоматически влияет на все связанные системы
- Каждый параметр имеет отправную точку для начальной настройки
- Параметры группируются по системам для удобства навигации

---

## Система характеристик

*Конкретные параметры будут добавлены при реализации ролевых механик*

### Общие принципы

**Модификаторы:**
- Плоские и процентные модификаторы применяются в определенном порядке
- Система поддерживает настраиваемые формулы расчета

**Валидация:**
- Автоматическая проверка корректности значений
- Настраиваемые минимальные и максимальные пороги

---

## Будущие параметры

По мере добавления новых систем их параметры будут добавляться в соответствующие разделы:

- **Ролевая система** - коэффициенты характеристик, базовые значения, формулы расчета
- **Система инвентаря** - лимиты веса, размеры стеков, базовые цены
- **Система боя** - модификаторы урона, шансы критических попаданий
- **Механика прогрессии** - требования опыта, бонусы за уровень
- **Система диалогов** - пороги проверок характеристик

---

## Рекомендации по использованию

### Для разработчиков
- Используйте параметры из этого раздела вместо hardcode значений
- При добавлении новых систем сразу выносите настройки в параметры
- Документируйте назначение каждого параметра

### Для тестирования
- Изменяйте параметры для проверки различных сценариев балансировки
- Ведите записи успешных комбинаций параметров
- Тестируйте крайние значения для выявления проблем

### Для балансировки
- Начинайте с отправных точек
- Изменяйте параметры постепенно (на 10-25%)
- Тестируйте изменения в различных игровых ситуациях
