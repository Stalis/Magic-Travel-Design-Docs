# 4. Механики

**Определение:** Геймплейные активности с жизненным циклом, которые используют системы для реализации игрового опыта.

**Принципы механик:**
- Имеют четко определенное начало, процесс и завершение
- Активируются событиями или действиями игрока
- Используют системы для реализации функциональности
- Предоставляют конкретный игровой опыт
