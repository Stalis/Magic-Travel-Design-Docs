# 2.2 Клавиатура + Мышь

## Основное движение и навигация

| Элемент управления | Функция |
| --- | --- |
| WASD / Стрелки | Передвижение партии по клеткам |
| Q/E | Поворот партии на 90° влево/вправо |
| Shift + Q/E | Быстрый разворот партии на 180° |
| Мышь | Нацеливание скиллов и атак, выбор целей |
| Колесико мыши | Приближение/отдаление камеры (переключение между двумя уровнями) |

## Переключение персонажей

| Клавиша | Функция |
| --- | --- |
| F1, F2, F3, F4 | Переключение между персонажами партии |

## Основные действия

| Клавиша/Мышь | Функция |
| --- | --- |
| ЛКМ | Основное действие (атака, взаимодействие, подтверждение) |
| ПКМ | Контекстное меню взаимодействий / Отмена действия в режиме нацеливания |
| Пробел | Завершить/пропустить ход текущего персонажа (удерживать для меню выбора) |
| Shift + Пробел | Переключение режимов хода (квази-реалтайм ↔︎ пошаговый) |

## Быстрый доступ к способностям

| Клавиша | Функция |
| --- | --- |
| 1-8 | Горячие клавиши для скиллов текущего персонажа |
| R | Быстрое использование основного оружия/атаки |
| T | Быстрое использование второстепенного действия |

## Инвентарь и предметы

| Клавиша | Функция |
| --- | --- |
| I | Инвентарь |
| Tab | Карточка персонажа (характеристики) |
| Z, X, C, V | Быстрое использование предметов (зелья, свитки и т.д.) |

## Системные функции

| Клавиша | Функция |
| --- | --- |
| M | Карта мира |
| Esc | Главное меню/пауза |
| Enter | Подтверждение в диалогах и меню |

## Дополнительные функции

| Клавиша | Функция |
| --- | --- |
| F9 | Скрыть/показать UI |
| F5 | Быстрое сохранение |
| F8 | Быстрая загрузка |
