# 1.1 Предел Фантазмы: Упрощенная версия

## Логлайн

Ты спустился в развалины легендарной лаборатории Фантазмы в поисках знаний, артефактов и славы. Но оказалось, что это место… продолжает жить. Правда, немного по-своему.

## Мир и контекст

### Общее описание

Фантазма — бывший 
исследовательский мегакомплекс, где изучали пространственные аномалии и 
артефактную энергетику. Эксперимент провалился, пространство замкнулось 
на себе, часть исследователей мутировала. Комплекс продолжает работать в
 автономном режиме как полубезумная машина.

### Текущее состояние

- Линейная структура уровней (коридоры → залы → боссы)
- Охранные системы работают по старым протоколам
- Мутировавшие обитатели враждебны по умолчанию
- Редкие исключения позволяют избежать боя через квест

---

## Основные механики

### 1. Прецизионное таргетирование (CORE FEATURE)

**Техническая реализация**: Полный контроль курсора мыши, клик по любой точке экрана.

**Игровые функции**:

- Изучение деталей окружения (описания объектов)
- Поиск секретов и скрытых проходов
- Точный выбор целей в бою
- Чтение записей, исследование улик

**Система описаний**:

- Каждый интерактивный объект имеет описание
- Ключевые объекты - расширенные описания с подсказками
- Система флагов для отслеживания изученных объектов

### 2. Бои-головоломки

**Техническая реализация**: Каждое столкновение имеет оптимальное решение через анализ.

**Типы решений**:

- Прямая атака (базовый, но не всегда оптимальный)
- Использование окружения (рычаги, ловушки, обрушения)
- Тактическое позиционирование
- Использование слабостей врагов
- Обход через секретные проходы (найденные через таргетирование)

**Факторы для анализа**:

- Расположение врагов
- Интерактивные элементы окружения
- Тип врагов и их уязвимости
- Доступные ресурсы игрока

### 3. Квестовые диалоги (МИНИМУМ)

**Техническая реализация**: Классическая система диалогов с ветвлениями.

**Типы взаимодействий**:

- Информационные NPC (дают подсказки/лор)
- Квесты "принеси/найди/убей"
- Редкие моральные выборы (убить/пощадить)
- Исключения: 1-2 NPC на игру, с которыми можно договориться вместо боя

**Ограничения**:

- Враги = враги (как в Larian играх)
- Нет системы репутации
- Нет динамических союзов

## Системы игрового мира

### Прогрессия

- **Линейная структура**: последовательное прохождение уровней
- **Классическая RPG прогрессия**: опыт, уровни, улучшение характеристик
- **Снаряжение**: традиционная система лута

### Система секретов

- **Скрытые проходы**: находятся через внимательное изучение стен
- **Секретные комнаты**: с дополнительным лутом и лором
- **Альтернативные пути**: обход сложных боев через исследование

### Информационная система

- **Лор через окружение**: история комплекса через детали
- **Записи исследователей**: объясняют происходящее
- **Контекстные подсказки**: помощь в решении головоломок боя

## Техническая архитектура

### Система взаимодействий

```
Клик на объект → Проверка типа → Описание/Действие
     ↓
Обновление флагов → Запись в журнал → Возможные новые интеракции

```

### Боевая система

```
Начало боя → Анализ ситуации игроком → Выбор стратегии
     ↓
Стандартный бой / Использование окружения / Обход → Результат

```

### Структура уровня

```
Вход → Коридор с врагами → Зал-головоломка → Комната с боссом → Выход
  ↓           ↓                    ↓                ↓
Секреты   Альт. пути        Опциональные       Лут + лор
                             взаимодействия

```

## Контентные требования

### Уровень детализации

- Каждый интерактивный объект: базовое описание
- Ключевые объекты: расширенное описание + подсказки
- Каждый уровень: 3-5 секретов для поиска

### Типы боев-головоломок (по приоритету)

1. **Окружение как оружие**: обрушить потолок, активировать ловушку
2. **Позиционирование**: заманить врага в выгодную позицию
3. **Слабости врагов**: использовать стихийные уязвимости
4. **Комбинированные**: несколько подходов одновременно
5. **Обход**: альтернативный маршрут через секреты

### Минимальная MVP структура

- **5-7 уровней** для демо-версии
- **10-15 уникальных типов боев** для полной версии
- **2-3 типа секретов** на уровень
- **1 опциональный мирный квест** на 3-4 уровня

- [ ]  5-8 полных уровней

### Фаза 3: Полировка (2-4 месяца)

- [ ]  Сюжетная арка и концовка

## Потенциальные проблемы и решения

### Проблема: Однообразие без дипломатии

**Решение**: Больше типов боев-головоломок, акцент на исследование

### Проблема: Низкая переиграбельность

**Решение**: Множественные секреты, альтернативные пути прохождения

### Проблема: Сложность создания уникальных головоломок

**Решение**: Система шаблонов + вариации, использование ИИ для генерации идей

---

## Метрики успеха

- **Использование таргетирования**: % изученных интерактивных объектов
- **Разнообразие решений**: как часто игроки используют нестандартные подходы
- **Скорость обнаружения секретов**: баланс сложности поиска
- **Время на уровень**: оптимальная длительность прохождения

---

## Scope контроль

### Жесткие ограничения

- **Максимум 15-20 уровней** для полной версии
- **Нет процедурной генерации** - только рукотворный контент
- **Один основной тип взаимодействия** с врагами (бой)
- **Линейная структура** без открытого мира

### Приоритеты разработки

1. **Прецизионное таргетирование** (уникальная фишка)
2. **Умные бои** (основной геймплей)
3. **Атмосфера через детали** (иммерсия)
4. **Квесты и диалоги** (только если есть время)

Эта версия на 60% проще в реализации, сохраняя уникальные особенности игры.
