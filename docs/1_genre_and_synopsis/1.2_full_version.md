# 1.2 Предел Фантазмы: Полная версия

## Логлайн
Ты спустился в развалины легендарной лаборатории Фантазмы в поисках знаний, артефактов и славы. Но оказалось, что это место… продолжает жить. Правда, немного по-своему.

## Мир и контекст

### Общее описание
Фантазма — бывший исследовательский мегакомплекс, построенный смесью магов, алхимиков и бюрократов. Здесь одновременно изучали искусственный интеллект, пространственные аномалии, артефактную энергетику и социальную инженерию.

### Текущее состояние
- Пространство замкнулось на себе
- Порталы работают нестабильно
- Часть исследователей исчезла, часть мутировала, но сохранила разум
- Комплекс продолжает работать в автономном режиме
- ИИ комплекса распознаёт некоторых как "потенциально совместимых субъектов"

### Обитатели
- **Мутировавшие исследователи**: сохранили интеллект, но изменились физически
- **Случайные искатели**: попали через порталы, не все дружественны
- **Охранные системы**: работают по старым протоколам
- **Торговцы и нейтральные NPC**: адаптировались к условиям комплекса

## Основные механики

### 1. Прецизионное таргетирование
**Техническая реализация**: Полный контроль курсора мыши, клик по любой точке экрана.

**Игровые функции**:
- Изучение деталей окружения (описания объектов, скрытая информация)
- Точный выбор целей в бою
- Интерактивность с мелкими объектами
- Чтение записей, граффити, исследование следов

**Интеграция в мир**: Обоснование через "исследовательский подход" - игрок ведет себя как ученый, изучающий каждую деталь.

### 2. Дипломатическая система
**Техническая реализация**: Диалоговая система с враждебными и нейтральными NPC.

**Механики**:
- Инициация диалога с потенциальными противниками
- Система убеждения/запугивания/подкупа
- Возможность смены союзов в бою
- Последствия дипломатических решений

**Ограничения**: 
- Не все NPC поддаются переговорам
- Некоторые требуют выполнения условий
- Ложная дипломатия (NPC может обмануть)

### 3. Бои-головоломки
**Техническая реализация**: Каждое столкновение имеет несколько вариантов решения.

**Типы решений**:
- Прямая атака (стандартный подход)
- Использование окружения (ловушки, механизмы)
- Дипломатическое решение
- Стравливание врагов друг с другом
- Обход/скрытность

**Факторы для анализа**:
- Состав врагов и их взаимоотношения
- Доступное окружение
- Ресурсы игрока
- Предыдущие действия игрока в локации

## Системы игрового мира

### Репутационная система
- **Локальная репутация**: отношения в конкретных зонах/с конкретными группами
- **Память NPC**: запоминание действий игрока
- **Динамические фракции**: формирование союзов на основе действий игрока

### Система информации
- **Детективные элементы**: восстановление истории по деталям
- **Контекстные подсказки**: информация доступна только при внимательном изучении
- **Многослойное повествование**: основная история + побочные линии через детали

### Адаптивный контент
- **Реакция на стиль игры**: мир меняется в зависимости от предпочтений игрока
- **Эволюция NPC**: развитие персонажей на основе взаимодействий
- **Изменение доступного контента**: открытие/закрытие путей в зависимости от репутации



## Техническая архитектура

### Система взаимодействий
```
Объект → Описание → Контекстное меню → Действие
     ↓
Проверка условий → Результат → Изменение мира
```

### Боевая система
```
Встреча → Анализ ситуации → Выбор подхода
    ↓
Дипломатия / Бой / Обход → Разрешение → Последствия
```

### NPC система
- **Состояния**: дружественный, нейтральный, враждебный, союзник
- **Атрибуты**: интеллект, агрессивность, жадность, лояльность
- **Память**: таблица действий игрока и реакций на них



## Контентные требования

### Уровень детализации
- Каждый интерактивный объект должен иметь описание
- Минимум 3 варианта описания для ключевых объектов (при разных подходах)
- Все NPC должны иметь базовую мотивацию и возможность диалога

### Балансировка решений
- Каждый подход к решению задач должен иметь плюсы и минусы
- Дипломатические решения не должны быть всегда оптимальными
- Агрессивный подход должен иметь последствия, но оставаться жизнеспособным

### Связность мира
- Действия в одной локации влияют на другие
- NPC помнят и обсуждают действия игрока
- Мир должен ощущаться живым и реагирующим



## Потенциальные проблемы и решения

### Проблема: Перегруженность информацией
**Решение**: Система фильтров важности, постепенное обучение игрока

### Проблема: Дисбаланс дипломатии
**Решение**: Жесткие ограничения на переговоры, система доверия

### Проблема: Сложность контента
**Решение**: Инструменты для быстрого создания вариативного контента



## Метрики успеха системы

- **Вариативность решений**: среднее количество подходов к решению задач
- **Использование дипломатии**: процент мирных решений конфликтов  
- **Детализация исследования**: процент изученных интерактивных объектов
- **Связность действий**: как часто прошлые решения влияют на новые ситуации



## Анализ реализации

### Готовые компоненты
- ✅ **Базовая архитектура** - основа системы (30-40% работы)
- ✅ **Система ходов** - самая сложная часть уже решена
- ✅ **Пространственная логика** - базовая функциональность работает

### Компоненты средней сложности
#### Прецизионное таргетирование
- **Сложность**: Техническая реализация простая, контент-ориентированная
- **Требования**: Описания для каждого объекта, система подсказок
- **Время разработки**: 2-3 месяца

#### Дипломатическая система  
- **Сложность**: Простая логика, большой объем контента
- **Этапы**: 
  - Базовая система диалогов: 1 месяц
  - Наполнение контентом: 3-4 месяца
- **Помощь**: Написание диалогов можно делегировать

### Компоненты высокой сложности
#### Бои-головоломки
- **Сложность**: Самая коварная часть проекта
- **Challenges**: 
  - Индивидуальное проектирование каждого боя
  - Система анализа ситуации и вариантов
  - Балансировка всех подходов
- **Время разработки**: 6-8 месяцев + постоянные итерации

#### Адаптивный мир
- **Риск**: Может стать бесконечной кроличьей норой
- **Компоненты**: ИИ NPC, репутация, память действий
- **Время разработки**: 4-6 месяцев

## Планирование проекта

### Бюджетные ограничения (100€/месяц)
- **Арт**: Готовые ассеты + заказные ключевые элементы
- **Аудио**: Базовый набор музыки и звуков
- **Инструменты**: Необходимые плагины и софт

### Временные рамки

#### MVP версия (8-12 месяцев)
- Упрощенная дипломатия
- 10-15 уникальных боев-головоломок  
- Базовое таргетирование
- Простая репутационная система

#### Полная версия (18-24 месяца)
- Все системы в полном объеме
- Богатый контент
- Полная полировка и балансировка

### Стратегия разработки

#### Поэтапный подход
1. **Таргетирование** (начать первым - простейшая реализация)
2. **Базовая дипломатия** (с помощью в написании текстов)
3. **Бои-головоломки** (в последнюю очередь - самое сложное)

#### Использование ИИ
- Генерация описаний объектов
- Создание базовых диалогов (с последующей обработкой)
- Идеи для головоломок боя
- Балансировка характеристик

#### Контроль scope
- 5 идеальных боев вместо 50 посредственных
- Простая репутационная система на старте
- Маленький, но детализированный мир

## Управление рисками

### Основные риски проекта

#### Feature Creep
- **Проблема**: Каждая система может разрастись в монстра
- **Решение**: Жесткие ограничения scope, MVP-подход

#### Контентная яма  
- **Проблема**: Много уникального контента = много времени
- **Решение**: Инструменты автогенерации, шаблонизация

#### Балансировка
- **Проблема**: Три разных подхода к бою сложно сбалансировать
- **Решение**: Итеративное тестирование, метрики эффективности

### Митигация рисков
- Регулярные ретроспективы и пересмотр scope
- Приоритизация core механик
- Раннее тестирование с фокус-группой
